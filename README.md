# Tour du Tanargue

Page statique pour une proposition de GR de Pays Tour du Tanargue en 3 jours,
au depart de Largentiere.

## Publication GitHub Pages

1. Creer un depot GitHub, par exemple `tour-du-tanargue`.
2. Pousser ce dossier sur la branche `main`.
3. Dans GitHub, activer Pages depuis `Settings > Pages`, source `Deploy from a branch`, dossier `/root`.

## Sources

- MonGR, fiche `GR de Pays Tour du Tanargue`.
- Decathlon Outdoor, `GRP Tour du Tanargue`.
- Wikimedia Commons, `Landes du Tanargue.JPG`, utilisee comme photo d'accueil.

La carte fournie est schematique et originale. Elle ne remplace pas une carte IGN,
une trace GPX officielle ou les consignes locales.
